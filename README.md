# OOP-individual-assignment-1# Agricultural Crop Yield Monitoring System

A beginner-friendly Python OOP project for recording farm crop yields.

## Features
- `Farmer` and `CropRecord` classes
- Attributes and object interaction
- One list (`crop_records`) stores crop records
- Instance method: `display_info()`
- Class method: `record_count()`
- Add/display records and calculate total crop yield

## How to run
Run `python agriculture_system.py` with Python 3.

## Digital Public Goods (DPG) alignment
- Open source: source code can be shared publicly.
- Accessible: simple text output.
- Privacy-respecting: sample data is fictional and no sensitive personal data is stored.
- Modular/reusable: classes and functions have separate responsibilities.
